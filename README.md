# FlowCore

> Open-source low-code platform for business process automation.

---

## About

FlowCore is an open-source platform that helps businesses automate customer request processing, workflows, and internal operations without writing code.

The platform combines CRM, dynamic forms, Telegram integration, Google Sheets synchronization, workflow automation, and a REST API into a single system.

> **Status:** 🚧 Work in Progress

---
